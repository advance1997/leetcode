## 先建立选择意识

| 主要需求 | 优先考虑 | 必须同时考虑的成本 |
| --- | --- | --- |
| 按下标读取、连续扫描 | 数组、动态数组 | 保序的中间插入与删除需要搬移元素 |
| 已定位节点后频繁修改连接 | 链表 | 按下标定位通常仍需 O(n)；单链表删除还可能需要前驱 |
| 按最近加入或最早加入的顺序处理 | 栈、队列 | 不擅长任意位置的查找 |
| 按键查找和计数 | 哈希表 | 平均性能依赖哈希分布，最坏情况需单独分析 |
| 有序查找或层级表达 | 搜索树或普通树 | 普通二叉搜索树可能退化，树高需要控制 |
| 重复取最值 | 堆 | 不保证所有元素整体有序 |
| 字符串前缀匹配 | 前缀树 | 节点和分支可能占用较多空间 |
| 描述任意连接 | 图 | 邻接表和邻接矩阵适用规模不同 |
| 合并集合并判断连通性 | 并查集 | 不直接维护完整路径，也不擅长删除连接 |

这些是选择入口，具体复杂度和适用条件在各专题展开，不将某种结构视为所有问题的通用最优解。

## 每个专题怎样学习

1. 画出逻辑关系与存储示意，先明确“一个元素”和“一个位置”的含义。
2. 手动执行访问、查找、插入和删除，数清需要处理多少元素。
3. 阅读 Java 示例，分清语言保证、API 行为和实现细节。
4. 对比其他结构，解释何时选择它、何时换用其他结构。
5. 通过关联题目练习，再脱离文档复述并手写关键操作。

专题包含概念、图解、复杂度、优势与局限、Java 用法、易错点、关联题目和验证记录。数据结构介绍不虚构 LeetCode 题号或难度；示例代码使用中文注释和必要的 Javadoc。后续每个专题配套可编译运行的 Java 实现，统一放在 `src/learning/datastructures/类别包/`，文档提供源码链接、运行方式和验证记录。数组入门示例目前保留在数组文档中。

每个专题先列出常用实现及覆盖进度，分别讲解结构差异、适用条件并提供 Java 实现与验证。不能只用一种实现代表整个专题；链表、栈、队列及哈希表的上述实现已完成，树专题已完成基础概念与二叉树构造、递归/迭代遍历，二叉搜索树增删查与退化验证也已完成，AVL 四种旋转与增删再平衡也已完成，红黑树颜色约束、增删修复及黑高验证也已完成；接下来学习多叉树的孩子列表表示与遍历。
