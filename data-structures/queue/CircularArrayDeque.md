# 数组双端队列（CircularArrayDeque）

[专题总览](Queue.md) · [Java 实现](../../src/learning/datastructures/queue/CircularArrayDeque.java) · [数组循环队列](CircularArrayQueue.md)

## 1. 从循环队列增加另一端操作

仍使用 elements、head、size，逻辑第 i 个位置映射到 `(head+i)%C`。不再只允许尾入首出，还支持首入、尾出、查看尾部。所有槽位均可使用，size=0 判空、size=C 判满；没有预留一个槽位。

构造默认容量 4，允许自定义非负容量，零容量会在首次加入时先扩到 1。负容量抛 IllegalArgumentException；空查看或删除抛 NoSuchElementException，不改变内容；允许所有 int 与重复值。快照从首到尾，独立于内部数组。

## 2. 六个端点操作

| 方法 | 核心位置 | 说明 |
| --- | --- | --- |
| addLast(value) | 逻辑偏移 size | 先扩容，再写入并增加 size |
| addFirst(value) | head 前一个槽位 | 先扩容，再回退 head 并写入 |
| removeFirst() | head | 保存值、清理、前进 head、减少 size |
| removeLast() | 逻辑偏移 size-1 | 保存值、清理、减少 size |
| peekFirst() | head | 只读 |
| peekLast() | 逻辑偏移 size-1 | 只读 |

size、isEmpty 为常数时间，toArray 按逻辑顺序生成快照。两端删除后若 size=0，均将 head 重置为 0。使用同一端加入/删除可作为栈，尾入首出可作为队列。

## 3. 首端回绕图解

容量 4，初始加入 10、20 后：

```text
物理下标：   0   1   2   3
初始数组： [10, 20,  0,  0] head=0 size=2，逻辑 [10,20]
addFirst(5)
回退 head：从 0 回到 3
写入后：   [10, 20,  0,  5] head=3 size=3，逻辑 [5,10,20]
addLast(30)
写入位置： (3+3)%4 = 2
写入后：   [10, 20, 30,  5] head=3 size=4，逻辑 [5,10,20,30]
```

Java 中 `(-1)%4` 是 -1，不能直接写 `(head-1)%C`。源码显式使用 `head==0 ? C-1 : head-1`。前进也使用边界分支；逻辑偏移相加用 long，避免 int 加法溢出。

## 4. 两端删除追踪

从上面的满状态出发：

| 操作 | 物理位置 | 返回 | 新 head/size | 逻辑序列 |
| --- | --- | --- | --- | --- |
| removeLast() | `(3+4-1)%4=2` | 30 | 3 / 3 | `[5,10,20]` |
| removeFirst() | 3 | 5 | 0 / 2 | `[10,20]` |
| removeLast() | 1 | 20 | 0 / 1 | `[10]` |
| removeFirst() | 0 | 10 | 0 / 0 | `[]` |

清槽位为 0 不代表元素值 0 非法，有效性依赖 head 与 size。检查必须先于计算 size-1，空队列时不能先计算尾部下标。

## 5. 满状态下的首插与扩容

若 `[10,20,30,5]` 这个物理状态继续 addFirst(1)，先按旧逻辑顺序复制为容量 8 的 `[5,10,20,30,0,0,0,0]`，head=0；再将 head 回退到 7 并写入 1，得到 `[5,10,20,30,0,0,0,1]`，逻辑顺序是 `[1,5,10,20,30]`。

先扩容再回退，不会覆盖旧头。不能直接按物理数组顺序复制，也不能错误地假设扩容后 head 永远保持 0——首插随后会再次回绕。

零容量先增长到 1，复制循环零次，不发生对 0 取模。通常翻倍，容量计算用 long 并限制在 Integer.MAX_VALUE 内；到达计数上限时显式抛 IllegalStateException，实际仍可能更早分配失败。

## 6. 正确性与复杂度

不变量：size 个有效元素按逻辑偏移连续占据环形槽位。首插前退一个空位再增加 size，新值成为逻辑第一个，旧序列次序不变；尾插追加到偏移 size；两端删除各移除对应端点，其他顺序不变。扩容复制第 i 个逻辑元素到新下标 i，保持语义。

逐次整体搬移的数组双端队列，首端插删最坏 O(n)。回绕消除了常规搬移，两端删除/查看 O(1)，两端加入均摊 O(1)、扩容单次 O(n)。证明来自几何增长累计复制 O(m)，不是每次扩容都只复制常数个元素。

n 为有效数量，C 为保留容量：总存储 O(C)，删除不缩容；快照时间与返回空间 O(n)。扩容时新旧数组同时存在，额外空间 O(n)（满时 n=C）。固定容量版本可避免复制，但必须定义满时拒绝行为，本实现采用可增长策略而非覆盖旧值。

相比链式双端队列，环形数组紧凑、无需每次分配节点，但有闲置容量与扩容成本。与普通 FIFO 队列相比，双端能力更强，却也更容易把调用端点混用，破坏业务顺序。

## 7. 运行示例

在仓库根目录执行，普通 JDK 可用 javac：

```bash
build_dir=$(mktemp -d /tmp/array-deque.XXXXXX)
java -m jdk.compiler/com.sun.tools.javac.Main -encoding UTF-8 \
    -d "$build_dir" src/learning/datastructures/queue/CircularArrayDeque.java
java -cp "$build_dir" learning.datastructures.queue.CircularArrayDeque
```

main 先尾入 10、20、30，首出 10，尾入 40，首入 5，尾出 40，然后按首端排空再复用：

```text
[10, 20, 30]
10
40
[5, 20, 30]
5
20
30
0
0
```
