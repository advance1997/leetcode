# 循环单链表（Circular Singly Linked List）

[返回导航](../README.md) · [单链表基础](LinkedList.md) · [Java 实现](../../src/learning/datastructures/linkedlist/CircularSinglyLinkedList.java)

学习日期：2026-11-10（北京时间）。本节使用无哨兵、只维护 tail 与 size 的实现，重点理解闭环维护、逻辑头尾和遍历终止。不对应特定 LeetCode 题目。

## 1. 为什么把尾节点连回头节点

普通单链表在尾节点遇到 null。若数据需要反复轮转，例如轮询参与者，可以让最后一个节点的 next 指向第一个节点，沿 next 就能继续下一轮。

```text
       head = tail.next
            ↓
           [10] → [20] → [30] ← tail
            ↑             │
            └─────────────┘
```

箭头代表 next 引用，节点不要求连续存储。环本身没有天然的“第一个”，tail 这个外部入口指定了逻辑头尾；改变入口可能改变序列含义，即使节点之间没有改线。

只保存 head 时，找到尾节点仍要扫描；保存 tail 则既能直接访问尾，又能通过 tail.next 访问头。因此本实现头插、尾插、头删都是 O(1)。但它仍只有 next，找尾的前驱仍需遍历，尾删并不会变成 O(1)。

## 2. 状态与接口约定

必须保持以下不变量：

- 空表：size=0，tail=null。
- 非空：tail.next 是逻辑头；所有有效节点的 next 非 null。
- 从逻辑头前进恰好 size 次返回同一个节点，之前不会提前回到头；环中恰好 size 个节点。
- 单节点：tail.next == tail；重复值不影响节点身份。

```text
空表： tail → null
单个： tail → [10] ─┐
               ↑───┘
```

Java 类位于 `src/learning/datastructures/linkedlist/CircularSinglyLinkedList.java`，包名 `learning.datastructures.linkedlist`。

| 接口 | 含义与边界 |
| --- | --- |
| size() | 有效节点数 |
| get(index) | 读取 `[0,size)` 下标 |
| insert(index,value) | 插入 `[0,size]` 位置，size 表示尾插 |
| remove(index) | 删除 `[0,size)` 位置并返回原值 |
| addFirst/addLast | 首尾插入 |
| removeFirst/removeLast | 首尾删除，空表抛异常 |
| indexOf(value) | 首次匹配的逻辑下标，找不到为 -1 |
| toArray() | 从逻辑头走一圈，返回独立数组 |
| reverse() | 原地反转连接与逻辑序列 |

允许任意 int 和重复值。非法下标抛出 IndexOutOfBoundsException，异常检查先于修改。计数到达 Integer.MAX_VALUE 时插入抛出 IllegalStateException，实际容量还受内存限制。节点不暴露，不支持并发修改。

## 3. 插入：头插与尾插改线相同，入口更新不同

初始 `[10,30]`，tail=30，head=10。头插 5：

```text
1. inserted.next = tail.next     5 → 10
2. tail.next = inserted          30 → 5
3. 保留 tail=30
结果顺序：5 → 10 → 30 → 回到 5
```

在同一初始结构尾插 40：

```text
1. inserted.next = tail.next     40 → 10
2. tail.next = inserted          30 → 40
3. tail = inserted              新尾变为 40
结果顺序：10 → 30 → 40 → 回到 10
```

不更新 tail 的尾插会被解释成头插，虽仍闭环，序列已经错误。因此“结构没断”不等于“操作语义正确”。

中间插入先找 index-1 的前驱，再执行“新节点接原后继、前驱接新节点”。例如 `[10,30]` 的下标 1 插入 20 得到 `10→20→30→10`，tail 不变。空表没有可读取的 tail.next，必须单独让新节点自环，并设置 tail。最后统一 size++。

**正确性：**将前驱到后继的一条边替换为经过新节点的两条边，其余边不动，环只增加一个节点；再按头尾语义维护入口。先保存后继，避免覆盖导致自环或丢失原节点。

## 4. 删除：缩短环并维护尾入口

以 `10→20→30→10` 为例：

| 删除位置 | 前驱 | 改线 | 新 tail 与逻辑序列 |
| --- | --- | --- | --- |
| 头 10 | 30 | 30.next=20 | tail=30，`[20,30]` |
| 中间 20 | 10 | 10.next=30 | tail=30，`[10,30]` |
| 尾 30 | 20 | 20.next=10 | tail=20，`[10,20]` |

删除尾节点时需要把 tail 更新为前驱。只剩一个节点时，前驱与被删节点是同一个对象，不能靠普通改线来表示空表，必须设置 tail=null。清理 removed.next 后 size--。引用清理不表示立即释放内存，回收由 JVM 决定。

删除的一般正确性来自把“前驱→被删节点→后继”替换为“前驱→后继”；唯一节点分支恢复空表不变量。

## 5. 遍历为什么不能等 null

非空环中每个 next 都是节点引用，`while (current != null)` 不会结束。常用办法：

1. 从头开始，只处理 size 个节点。本实现查找、快照采用此方式，空表循环执行零次。
2. 非空时用 do-while，走完一步后比较节点身份是否回到起点。不能在第一次访问前就判断 current != head，否则一次也不执行。

比较的是对象身份，不是 value。`[7,7,7]` 的第一个 7 和第二个 7 是不同节点；按值停止会漏数据。按 size 限定次数依赖结构不变量，不能用它掩盖错误的短环，因此测试还要检查实际节点数和闭合位置。

## 6. 反转：闭环边也要反向

普通单链表反转时 previous 初始为 null；这里初始为旧 tail，才能让旧头反向连向旧尾。

对 `10→20→30→10`：

| 步骤 | 本轮 current | 保存的原 next | 修改后的 next | 下一轮 previous/current |
| --- | --- | --- | --- | --- |
| 1 | 10 | 20 | 10→30 | 10 / 20 |
| 2 | 20 | 30 | 20→10 | 20 / 30 |
| 3 | 30 | 10 | 30→20 | 30 / 10 |

恰好处理 size 次后，把 tail 设为旧 head=10，新 head 就是 tail.next=30，逻辑顺序为 `[30,20,10]`。

```java
Node originalNext = current.next;
current.next = previous;
previous = current;
current = originalNext;
```

此片段位于类内部，完整实现见源码。循环每轮处理原序列中的一个节点，先保存原 next，确保不会因改线丢失下一步；处理 n 个节点后，每条边均反向，原头成为新尾。中途可能暂时出现局部环，不允许并发使用。空表和单节点直接返回。

## 7. 复杂度、替代方案与场景

n 为有效节点数。链表总存储 O(n)，插入增加一个节点；除快照返回空间 O(n) 外，操作辅助空间 O(1)。

| 操作 | 本实现 | 原因 |
| --- | --- | --- |
| size、头插、尾插、头删 | O(1) | tail 和 tail.next 可直接取得 |
| 尾删 | O(n) | 需要找到尾的前驱 |
| 一般按下标访问、插删 | 最坏 O(n) | 单向定位；get 尾下标额外做了 O(1) 特判 |
| 查找与快照 | O(n) | 最多遍历一圈 |
| 原地反转 | O(n) | 改变每个节点的一条边 |

只存 head 的朴素版本尾插需扫描，维护 tail 消除这部分重复定位，代价是每次删除尾部和反转都要同步更新入口。用数组或栈保存所有值再重建逆序需要 O(n) 额外空间，而原地反转只使用固定引用，但更依赖改线顺序。

适用于循环轮询、约瑟夫问题的过程模拟。一般下标删除并不能使约瑟夫模拟自动达到 O(n)；应结合游标与问题分析。与普通单链表相比，循环结构方便连续轮转，但终止条件更容易写错；与循环双向链表相比省一个前驱引用，却不方便后退和删尾。

Java 标准库没有直接提供这种公开的循环单链表容器；LinkedList 是双向链表，不能把其 API 当作本结构的自动实现。

## 9. 边界与复述

重点检查：空表查找返回 -1、空表 get/remove 抛异常、单节点删除后 tail=null、双节点删头或删尾恢复自环、重复值查找返回首个下标、反转两次恢复序列、快照修改不影响链表、非法下标不改结构。

> 循环单链表把尾连回头，我保存尾指针，因此能 O(1) 找到头尾。头插与尾插的改线相同，区别是尾插还要移动 tail。删除唯一节点必须单独处理；遍历按节点数量或回到起点结束，不能等 null。它没有前驱引用，所以尾删仍需 O(n)。
