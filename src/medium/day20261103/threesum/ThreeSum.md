## 1. 题意与约束

给定整数数组 nums，返回所有和为零、不重复的三元组。每组三个元素必须来自三个不同下标，数值允许相同。返回数值而不是下标，答案顺序不限。

- `3 <= nums.length <= 3000`。
- `-100000 <= nums[i] <= 100000`。
- `[-1,0,1,2,-1,-4]` 返回 `[[-1,-1,2],[-1,0,1]]`。
- `[0,1,1]` 返回 `[]`。
- `[0,0,0]` 返回 `[[0,0,0]]`。

本次通过 [Doocs 公开题面镜像](https://github.com/doocs/leetcode/blob/main/solution/0000-0099/0015.3Sum/README.md) 核对题意、难度和约束，没有重新访问官方页面，不标注未经核实的公司频率。

## 2. 先分清三件事

1. **下标不能重复**：一个位置不能使用两次。
2. **数值可以重复**：`[-1,-1,2]` 合法，只要两个 -1 来自不同位置。
3. **答案不能重复**：不同下标组合若构成相同数值三元组，只返回一次。

因此不能先把整个数组去重：那样会把 `[0,0,0]` 变成 `[0]`，直接丢掉答案。也不能把本题等同于“两数之和”的返回下标要求；本题允许为搜索方便重排元素。

## 3. 暴力解法：枚举三条不同下标

最直接的方法是三层循环，满足 `first < second < third`，检查三数之和是否为零。这自然保证下标不同，枚举量为：

```text
C(n,3) = n(n-1)(n-2)/6
```

还需要解决数值重复。一般可以将命中结果规范为排序后的三元组并放入集合。本仓库的暴力实现改为先排序副本，在每个枚举层跳过相邻的相同候选，避免引入额外去重集合：

```text
排序副本 sorted
for first：
    若与上一轮 first 的值相同，跳过
    for second 从 first+1 开始：
        若与本层上一轮 second 的值相同，跳过
        for third 从 second+1 开始：
            若与本层上一轮 third 的值相同，跳过
            若三个值之和为零，加入答案
```

second 的去重条件必须是 `second > first + 1`，而不是简单的 `second > 0`；third 同理。它们只跳过本层重复的选择，允许不同选择层使用相同值。

任何合法数值三元组都可以写成非递减的 `(a,b,c)`。依次选择其最早可用位置即可保留该组合，跳过后续同值选择只删除重复组合。排序和去重没有消除最坏的三层枚举，时间仍为 O(n³)。n 为 3000 时，未剪枝的下标组合约为 45 亿，不适合作为大输入的主算法。

## 4. 优化的入口：固定一个数，问题减少一维

如果第一个数 a 已确定，剩下的问题就是找：

```text
b + c = -a
```

这与“两数之和”有关，但本题需要找出所有不重复的数值组合。固定 a 后可以用哈希查找，但结果去重需要额外处理。

排序能同时带来两个好处：

- 相同值相邻，方便跳过重复选择。
- 两端数值有单调性，可以根据总和偏大或偏小决定移动方向。

本实现复制数组再排序，明确保留原输入。只返回数值，因此不需要保留原始下标映射。

## 5. 固定首元素后的双指针规则

固定 first，令 `left = first + 1`，`right = n - 1`。

- 和小于零：左指针右移，尝试更大的数。
- 和大于零：右指针左移，尝试更小的数。
- 和等于零：记录答案，跳过当前左右数值的重复项，继续寻找其他组合。

这里不能沿用盛水容器的“移动短边”规则。本题使用的是排序后的数值单调性，而不是面积上界。

**为什么和偏小时可以排除 left？** 当前 right 是剩余区间中最大的候选。若 a + sorted[left] + sorted[right] 仍小于零，把 right 换成更小的内部候选，只会更小。因此当前 left 与任何剩余右端都不能组成零和，可以安全丢弃。

**为什么和偏大时可以排除 right？** 当前 left 是剩余区间最小的候选。若总和已大于零，换成更大的左端仍会偏大，因此当前 right 可以安全丢弃。

## 6. 图解官方示例的完整扫描

```text
原数组：[-1, 0, 1, 2, -1, -4]
排序后：[-4,-1,-1, 0,  1,  2]
下标：    0  1  2  3   4   5
```

first 固定首数；L、R 为当前左右指针。下面列出每一次实际的求和状态：

| first / 首数 | L / 左值 | R / 右值 | 和 | 操作 |
| --- | --- | --- | ---: | --- |
| 0 / -4 | 1 / -1 | 5 / 2 | -3 | L → 2 |
| 0 / -4 | 2 / -1 | 5 / 2 | -3 | L → 3 |
| 0 / -4 | 3 / 0 | 5 / 2 | -2 | L → 4 |
| 0 / -4 | 4 / 1 | 5 / 2 | -1 | L → 5，相遇结束 |
| 1 / -1 | 2 / -1 | 5 / 2 | 0 | 记录 `[-1,-1,2]`，跳同值后 L=3、R=4 |
| 1 / -1 | 3 / 0 | 4 / 1 | 0 | 记录 `[-1,0,1]`，跳同值后相遇 |
| 2 / -1 | — | — | — | 首数重复，跳过整轮 |
| 3 / 0 | 4 / 1 | 5 / 2 | 3 | R → 4，相遇结束 |

```text
固定 -1 的第一轮：
[-4, -1, -1, 0, 1, 2]
      F   L         R     -1 + -1 + 2 = 0

跳过已使用数值后：
[-4, -1, -1, 0, 1, 2]
      F       L  R        -1 + 0 + 1 = 0
```

## 7. 去重是本题的重点

### 首元素去重

`first > 0 && sorted[first] == sorted[first-1]` 时跳过。前一次同值首元素搜索的后缀更大，已经覆盖本次可能产生的数值组合。

跳过首元素不等于禁止重复数值进入同一组。例如固定第一个 -1 后，left 可以指向第二个 -1，所以 `[-1,-1,2]` 仍会找到。

### 命中后的左右去重

对于固定 a，某个 b 对应的 c 必须等于 `-a-b`。已经记录 `(a,b,c)` 后，重复 b 或重复 c 只会产生相同答案。

例如：

```text
[-2, 0, 0, 2, 2]
  F  L        R     命中 [-2,0,2]

跳过两个 0 与右侧重复 2，指针相遇，答案只记录一次。
```

代码保存本次 leftValue、rightValue，用两个 while 跳过相同值，必须检查 `left < right` 避免越界或复用同一位置。

### 全零数组为什么仍有答案？

`[0,0,0,0]` 固定第一个零时，左右来自两个不同位置，记录一次 `[0,0,0]`，跳同值后结束。下一轮首数重复被跳过，最终只有一组。

## 8. 正确性、剪枝和终止

合法性：始终保持 `first < left < right`，因此三个下标不同；仅在和为零时输出；排序保证三元组按非递减顺序表示。

完整性：对于每个不同首数，双指针只排除已经证明不可能为零的候选。命中后的跳同值只排除重复答案。遍历所有首数，因此不会漏掉不同数值组合。

唯一性：首数相同的搜索只执行一次；同一首数下，同一对左右数值只记录一次，因此不存在重复三元组。

提前结束：如果 sorted[first] > 0，后面都不小于它，三个数之和必然为正，后续首数也不可能有解。这里不能改成 `>= 0`，否则会漏掉 `[0,0,0]`。

终止性：外层 first 单调递增；内层每轮至少移动一个指针，命中分支也一定先推进 left。区间宽度持续减小，最终相遇。

## 9. 复杂度与优势代价

令 n 为输入长度，k 为不同三元组数量。

| 方案 | 最坏时间 | 不计输出的辅助空间 | 输出空间 | 修改原输入 |
| --- | --- | --- | --- | --- |
| 排序副本后三重枚举 | O(n³) | O(n) | O(k) | 否 |
| 排序副本后固定首数与双指针 | O(n²) | O(n) | O(k) | 否 |

对于每个 first，left 与 right 总共移动 O(n) 次；最多 O(n) 个 first，因此扫描为 O(n²)。排序不会改变总的平方级上界。内层去重 while 不会额外乘上 n，因为指针不会回退，它们共享本轮的线性移动预算。

本实现复制数组，辅助空间至少 O(n)，不能照抄“排序双指针只用 O(1) 空间”的说法。排序内部空间取决于具体 JDK 实现，本实现总体以 O(n) 辅助空间计；包括答案后的总空间为 O(n+k)。答案数最坏可达平方级，不能忽略实际输出的内存需求。

三个数的和位于 [-300000,300000]，int 安全。若泛化为任意 int 数组，应在加法前提升为 long 并增加边界验证，不能等已经溢出后再转换。

优化的收益是少枚举一层，并直接生成去重答案；代价是排序、复制数组，以及更复杂的去重证明。暴力版本仍适合小输入的理解和验证。

## 11. 面试表达与专题联系

> 先三重枚举三个不同下标，最坏立方级。固定一个数后，其余两个数的目标和确定。排序既让重复值相邻，也让剩余两数可以通过双指针线性查找：和偏小排除左端，和偏大排除右端，因为排序保证换成其他候选也不能改善到目标。命中后跳过两端同值，外层跳过重复首数，就能返回所有不重复三元组。总时间 O(n²)，本实现为保留输入复制数组，辅助空间 O(n)。

复习时解释：为什么不能先将数组去重？为什么可同时推进命中后的两端？为什么首数为零不能直接退出？嵌套去重 while 为什么不使时间变成立方级？

本题属于双指针专题的综合题。移动零维护有效前缀，盛水容器排除面积不可能更优的边界，本题则利用有序性排除不可能达到目标和的候选。三者共同点是必须证明移动安全，而不是记忆同一个模板。

后续仍在本专题中逐步学习变式，例如第 16 题“最接近的三数之和”或第 18 题“四数之和”，分别关注目标差值和更多固定元素、溢出处理，不直接跳到无关类别。
